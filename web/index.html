Switch2-Pico

… USB …
Connect to your dongle over USB. Plug in the Switch2-Pico, click Connect over USB and choose it. Its name follows the mode: "Pro Controller", "DualSense Edge Wireless Controller", "DualSense Wireless Controller", "Controller" (Xbox 360) or "WUP-028" (GameCube adapter). Each mode is a separate USB device to the browser, so the first time in a mode it has to be chosen once; after that the page connects by itself. Needs Chrome, Edge or another Chromium browser. Linux: install the udev rule from the README first. If WebUSB is turned off on the dongle, use the Wi-Fi page instead (tap BOOTSEL, join Switch2-Pico-XXXX, open http://192.168.4.1).

Paired controllers

minutes without use

The controller then sleeps to save its battery; press any button to reconnect.

To pair: hold the small Sync button on the Switch 2 controller until the lights sweep. The dongle pairs automatically and remembers it; afterwards any button press wakes and reconnects it. Any of the paired controllers can connect, one at a time. Pairing one more when the list is full forgets the oldest pairing.

USB and system

Settings for

Mode

Each controller type keeps its own mode. When a controller connects and its mode isn't the one the dongle is in, the dongle restarts in that mode first; the controller connects right after.

Shortcut on the controller

On the controller, hold C + Home until its lights blink, then press a button below to switch to that mode (the dongle restarts; the choice is kept for this controller type). C + Home again, or a few seconds without pressing anything, leaves without a change. Buttons set to – are ignored; with every button set to – the shortcut is off.

Button mapping

Each mode keeps its own mapping; this follows the controller's mode (above) unless you pick another. The picture shows the controller live: pressed buttons light up and the sticks move.

Haptics test

Plays feedback on the connected controller. Left / right motor play the classic rumble the DualSense and Xbox modes use (strong left, weak right, each on its own side). The effects are the ones the shortcuts use; the built-in samples (1–7) are stored in the controller: 1 buzz, 2 buzz and two beeps, 3 the "ba-thump" it plays when it connects (also used for mode select), 4 the pairing "ka-chink", 5 a heavier 3, 6 and 7 the two halves of 4.

Firmware update

The dongle restarted as a USB drive (NICENANO, FTHR840BOOT or RP2350). Choose that drive and the firmware is written to it; the dongle installs it and restarts by itself.
